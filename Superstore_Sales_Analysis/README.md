# Superstore Sales Analysis | Excel Dashboard

## Project Overview
This project uses Microsoft Excel to analyze Superstore sales data and build an interactive dashboard for monitoring sales performance, profitability, products, customers and shipping.

The workbook demonstrates practical data cleaning, transformation, reporting and dashboard development skills relevant to Data Analyst, Business Analyst and MIS reporting roles.

## Objectives
- Analyze overall sales, profit, quantity and order performance.
- Compare sales and profitability across categories, sub-categories, regions and shipping modes.
- Identify top-performing products and customers, as well as products with low profitability.
- Track sales trends over time.
- Build interactive reports to support business decision-making.

## Tools & Excel Features
- **Microsoft Excel**
- Excel Tables and structured references
- Power Query for data cleaning and transformation
- Data Validation and conditional formatting
- Lookup and aggregation formulas
- PivotTables and PivotCharts
- Slicers for interactive filtering
- KPI cards and dashboard reporting

## Key Features
- **Interactive Dashboard:** Visual summary of sales and profitability.
- **KPI Cards:** Total Sales, Total Profit, Profit Margin, Total Orders and Total Quantity.
- **Sales Analysis:** Performance by category, sub-category, region and shipping mode.
- **Product Analysis:** Top products by sales and profit, including low-profit products.
- **Customer Analysis:** Identification of top customers by sales.
- **Time Analysis:** Yearly and monthly sales trends.
- **Trackers:** Separate sales, order, and product trackers for targeted analysis.
- **Data Quality Controls:** Validation rules and conditional formatting to highlight important values and statuses.

## Business Questions Addressed
- Which product categories generate the highest sales and profit?
- Which products perform best and which generate the lowest profit?
- Who are the top customers by sales?
- Which regions contribute most to sales and profitability?
- How do sales change over time?
- How does performance vary by shipping mode?

## What I Learned
- Preparing and organizing data for analysis.
- Building reusable Excel reporting workflows.
- Summarizing business data with PivotTables.
- Creating interactive dashboards using slicers.
- Using formulas and validation controls to improve reporting accuracy.
- Presenting business metrics in a clear, structured format.

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard sheet to explore the KPIs and charts.
4. Use the available slicers to filter the analysis.
5. Explore the tracker and PivotTable sheets for more detailed insights.

## Conclusion
This project demonstrates how Microsoft Excel can be used to transform raw sales data into structured reports and an interactive dashboard for business performance monitoring.
